[해시태그 규칙, 샘플판]
이 파일은 공개용 예시다. 팀 고유 규칙이 있으면 같은 구조로 rules/local.md에 적어 두면 이 파일 대신 그 파일이 프롬프트에 들어간다.

Call Result (필수, 아래 중 하나를 반드시 선택):
- #Opportunity : 영업기회가 생긴 경우. 다음 액션(견적·데모·미팅)이 잡혔거나, 도입 시점과 예산이 확인된 경우.
  자료만 보내 주기로 한 정도는 영업기회로 보지 않는다.
- #Nurture : 지금은 영업기회가 아니지만 관심과 잠재 수요가 있어 계속 접촉할 가치가 있는 고객.
- #Callback : 재통화 약속이나 요청이 있는 경우.
- #NoNeed : 수요가 없는 경우. 고객이 말한 이유를 콜로그에 상세히 남긴다.
- #NoPickup : 전화 미연결 (부재중, 연결 실패).
- #Unreachable : 3회 이상 응답 없음, 연락 가능한 번호 확인 불가.
- #DoNotContact : 고객이 연락을 원하지 않는다고 분명히 말한 경우.
- #Invalid : 잘못된 번호, 퇴사·이직, 대상이 아닌 연락처(학생·개인 등).

부가 태그 (해당 시 Call Result 태그에 추가):
- #NewContact : 새 담당자 연락처를 확보한 경우. 이름·직책과 획득 경로를 함께 기록.

[콜로그 작성 형식, 샘플판]

1) 주 태그가 #Opportunity 또는 #Nurture 인 경우, 아래 B·W·A·N·T 형식으로 작성:
#태그 (부가 태그 있으면 같이)
[B] Business: 회사가 무엇을 하는지, 사업 현황
[W] Wants: 고객이 하고 싶어하는 것 (프로젝트·방향)
[A] Authority: 통화 상대의 직책·의사결정 구조, 확보한 연락처
[N] Needs: 니즈·페인포인트 (기술적/비즈니스적)
[T] Timeline: 도입·시작·확장 시점
- Next: 다음 액션 (무엇을, 누구에게, 언제까지)
※ 전사에서 파악 안 되는 항목은 "미파악"으로 남기고 지어내지 말 것. 항목 자체를 빼지도 말 것.

2) 그 외 태그(#NoNeed, #Callback, #NoPickup 등)는 짧게:
#태그
- 판정 근거 불릿 2~4개 (고객이 실제로 말한 내용 기반). #NoNeed는 이유 필수.
- Next: 다음 액션 (없으면 생략)

공통 규칙:
- 한국어, 간결한 불릿. 고객이 쓴 인상적인 표현은 따옴표로 보존.
- 전사에서 확인된 사실만 쓴다. 추측은 "~로 파악", "~추정"으로 표시하고 대화에 없는 내용은 지어내지 않는다.
- 신규 연락처 확보 시 이름/직책과 획득 경로를 기록.
- 전사 오류로 보이는 단어는 문맥으로 보정하되 확신 없으면 (?) 표시.
